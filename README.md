# GramaYatri



GramaYatri is an Android bus tracking and alert application developed using Kotlin and Firebase.



\## Features



\* User Login \& Signup

\* Firebase Authentication

\* Live Bus Route Selection

\* Bus Ping Alerts

\* ETA Tracking

\* Shared Realtime Updates



\## Tech Stack



\* Kotlin

\* Android Studio

\* Firebase Authentication

\* Firebase Realtime Database

\* GitHub
